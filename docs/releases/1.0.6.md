# ED-Frame 1.0.6 — Powerplay coverage and observation times

Mining Finder now handles explicit unoccupied systems consistently and keeps Powerplay evidence tied to its supporting observation time. This maintenance release includes the 1.0.5 fixes and accompanies the live catalog server 0.9.1.

- **Acquire targets:** explicit unoccupied observations survive ingestion, storage and lookup even without a participating Power. Reinforce and Undermine reject currently unoccupied systems.
- **Original evidence times:** local arrivals, merged rings and Spansh markets retain a separate Powerplay time. New ring confirmations, commodity quotes or presence observations cannot refresh older control/state/participant evidence. Metadata without a usable Powerplay time remains unconfirmed.
- **Clear missing/outdated status:** evidence older than 24 hours has a separate label. Exact server checks distinguish systems not yet observed from observations that are too old.
- **Consistent snapshots:** newer complete observations replace old participants and controllers. Unoccupied snapshots clear old control. Timestamp comparisons handle time zones and fractional seconds.

Coverage depends on actual public observations; this update does not invent facts for unobserved systems. Confirmed routes do not guarantee in-game merit payouts or mining yield. Existing profiles and retained history are preserved.

**Download:** extract `ED-Frame-1.0.6-Windows.zip` into a separate folder and start `ED-Frame.exe` with `_internal` beside it. Your existing profile is reused. Source code and SHA-256 checksums are separate assets.

The new 1.0 release line succeeds the historical EDEC/ED-Frame numbering. Existing tags and downloads remain available; use GitHub's latest release link.

## Deutsch

Ausdrücklich unbesetzte Systeme bleiben als Acquire-Ziele erhalten. Powerplay-Angaben behalten ihren eigenen Beobachtungszeitpunkt — auch bei lokalen Ringdaten, zusammengeführten Quellen und Spansh-Märkten. Neuere Ringbestätigungen, Marktpreise oder Präsenzmeldungen können alte Kontrollmeldungen nicht auffrischen. Angaben ohne verlässlichen Zeitpunkt bleiben unbestätigt.

Veraltete Powerplay-Nachweise werden gesondert angezeigt. Server 0.9.1 unterscheidet bei gezielten Prüfungen zwischen „noch nicht beobachtet“ und „Beobachtung zu alt“. Fehlende öffentliche Beobachtungen bleiben unbekannt. Profildaten und gespeicherte Historien bleiben erhalten.

Das vollständige Windows-ZIP in einen separaten Ordner entpacken und dort `ED-Frame.exe` starten. `_internal` muss daneben bleiben; dein vorhandenes Profil wird weiterverwendet.
