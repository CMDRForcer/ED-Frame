# ED-Frame 1.0.7 — faster broad mining searches and targeted Powerplay checks

Broad mining searches now prepare commodity/ring rules once per query and share one exact market read between planning and diagnostics. Background searches retain known free-text start-system coordinates, restoring regional market results even when a different system is being warmed. This maintenance release accompanies catalog server 0.9.2.

- **Less repeated work:** ALL COMMODITIES with frozen populated inputs improved from 33 to 19 seconds at 250 LY and from 75 to 42 seconds at 500 LY for the first domain-worker calculation. Warm calculations improved from 29 to 17 and from 66 to 32 seconds. These are calculation timings, not complete UI/live-search times; Platinum timings were essentially unchanged.
- **Correct regional markets:** the worker uses the exact captured ring view to resolve known free-text origins. Results and order are unchanged by the performance optimization; this separate correctness fix intentionally restores previously omitted regional offers.
- **Targeted Powerplay supplementation:** server 0.9.2 can check up to six missing systems against public Spansh snapshots per verification pass. Current explicit EDDN control is reused first. Names, addresses, coordinates, control/state and original observation times are checked; older or equal-time source data cannot replace newer EDDN facts.
- **Bounded requests:** per-worker concurrency, request budgets, caches and shorter deferred/error retries bound upstream work. The existing community connection switch controls this lookup.

**Remaining limits:** missing source fields remain unknown. This update does not guarantee yield, stock, merit payouts or complete galaxy coverage. In the populated offscreen Qt test, the broad 500-LY search still took about 53 seconds to show its first list, peaked at 2.43 GiB RAM and produced event-loop gaps up to 1.71 seconds. The existing 50,000-row regional transfer bound remains. Further performance work follows separately.

Validation: 1,309 app tests, 158 server tests, 24 isolated real-PostgreSQL assertions and the packaged asynchronous QML smoke test covering 33 areas passed before publication. See the [measurement report](../../reports/mining_complete_benchmark_2026-10-09.md) for scope and reproduction.

**Download:** extract `ED-Frame-1.0.7-Windows.zip` into a separate folder and start `ED-Frame.exe` with `_internal` beside it. Your existing profile is reused. Source code and SHA-256 checksums are separate assets.
