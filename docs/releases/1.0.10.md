# ED-Frame 1.0.10

## English

**Set up your cockpit in minutes, with a tour of every area.**

- **Skippable onboarding:** Journal folder/status, real connection defaults, language and theme, followed by a tour derived from the sidebar. Back, Next, Skip and Esc work throughout; changed settings are saved immediately. Existing completed profiles are preserved. Reopen it from Settings â†’ OPEN ONBOARDING.
- **Accessible, responsive layout:** pictograms, keyboard controls and scrolling across all six themes, four languages and supported UI scales.
- **Active installation counts:** release builds automatically send only a random installation ID and app version, at most once per UTC day with the catalog enabled. The ID is recognizable across days and shared across Commander profiles; view/copy it in Settings â†’ About. No hardware IDs, Commander names/FIDs, Journals or activity data are sent. Records expire after 90 days; the database stores no IP addresses. Disabling the catalog or setting EDFRAME_NO_USAGE_PING=1 prevents pings; development builds never ping.
- **Catalog server 0.9.5:** private, token-protected DAU/WAU/MAU and version counts, daily retention cleanup, faster public statistics and market synchronization, bounded collector retries, and fewer redundant outfitting writes.
- **Stability:** cancel a delayed trading-details callback when its page unloads.

Installation counts remain private; the website continues to show public catalog statistics only. Existing proxy/access-log settings are preserved.

**Validation:** 1,425 application tests, 221 server tests on the Linux candidate and 22 isolated PostgreSQL/HTTP checks passed before release. The release workflow checks the source and packaged application again before publishing downloads.

**Install:** quit the previous app, including its tray process. Extract the complete ED-Frame-1.0.10-Windows.zip into a new folder and start ED-Frame.exe with _internal beside it. Python is bundled and existing profiles are reused.
