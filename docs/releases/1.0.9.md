# ED-Frame 1.0.9 — trading loops and a refreshed cockpit

**Plan the whole trade, find more commodities and keep your cockpit responsive.**

- **Trading loops:** NAV now finds A → B → A routes with separate outbound and return cargo, estimated profit, purchase costs, travel distance and quote age. Set cargo capacity, starting budget, origin, radius, landing pad and carrier access; compare total profit, combined margin per tonne or distance. Copy either destination, expand the details or recheck prices when ready.
- **More commodity offers:** Fleet Carriers are included by default, and the commodity list includes 46 additional goods in the catalog checked for this release, including Lithium Hydroxide and Bromellite. Choose a manual starting system or an unlimited search radius. Prices, quantities and observation dates remain visible; unlimited searches return up to 100 offers in the selected order.
- **A consistent cockpit:** pictograms, clearer headings, coordinated cards and action buttons connect the workspaces across all six themes. Refreshed commodity and trading cards make the useful numbers easier to compare. Translations, narrow layouts and empty states have been improved.
- **Smoother startup and navigation:** QML loads asynchronously. NAV search inputs survive page changes within the same session, and selected commodities/categories survive language changes. Manual trade searches use the interactive background queue within the existing CPU and memory limits.
- **Correct combined-margin ranking:** affordable outbound and return cargo are selected together, including the funds available after the first sale. The matching correction is already active on the ED-Frame catalog server **0.9.4**.

Trading suggestions come from a bounded regional market selection, with coverage shown in the result. They do not promise a galaxy-wide optimum. Original quote dates are preserved; prices, stock and demand can change before arrival. Large cold searches can still take time.

**Validation:** 1,406 application tests and 182 server contract tests passed on the prepared source. The fresh Windows package is checked through 35 functional smoke areas, including separate Mining, Journal and Powerplay workers. The GitHub release workflow repeats the application suite and source/package checks before publishing the downloads. See the [application audit](https://github.com/CMDRForcer/ED-Frame/blob/1.0.9/reports/app_audit_2026-10-11.md).

**Install:** quit the old app, including its tray process. Extract the complete `ED-Frame-1.0.9-Windows.zip` into a new folder and start `ED-Frame.exe` with `_internal` beside it. Python is bundled; existing profiles are reused. Full project source and `SHA256SUMS.txt` are separate downloads.
