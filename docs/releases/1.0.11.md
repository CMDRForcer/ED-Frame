# ED-Frame 1.0.11

Portable updates are now part of the cockpit. ED-Frame can notify you of a new release, download it in the background and install it after you choose **Update and restart**.

## What's new

- A quiet sidebar notice and **Settings → About** update controls, translated into English, German, Spanish and French across all six themes.
- Automatic release checks at most once per UTC day, plus manual checks. Optional automatic downloads are off by default; downloads show progress and can be cancelled.
- GitHub SHA-256 verification and a complete, versioned file manifest. Only regular releases of the ED-Frame repository are offered; the old 1.5 release line is handled correctly.
- A copied updater waits for the app to exit before backing up every local profile and replacing only the program folder. Plans, wishlists, credentials, retained data and the shared installation ID are preserved.
- The old program and profile backup are retained. Failed replacement or startup restores them; backups can be opened from About. Allow additional disk space for downloads, the previous app and backups.
- Source/development builds never check automatically or replace their checkout. Automatic checks can be disabled in About; EDFRAME_NO_UPDATES=1 disables all checks. Update checks use GitHub independently of the catalog connection and send no installation ID or Commander/Journal data.

## Install this release

**Versions up to 1.0.10 do not contain the updater. Install 1.0.11 manually once.** Quit the old app, including its tray process; extract the complete **ED-Frame-1.0.11-Windows.zip** into a new writable folder and start ED-Frame.exe with _internal beside it. Python is bundled. Existing data under %LOCALAPPDATA%/ED-Frame is reused. Subsequent compatible releases can be installed from the app.

Catalog server **0.9.5** remains compatible; this release requires no server deployment.

## Validation

- 1,451 application tests passed locally before publication, with targeted updater, translation and QML checks repeated after final layout changes.
- Real Windows packaged tests verified successful replacement and failed-start rollback, including two synthetic profiles, plans, credentials and the installation ID.
- QML was checked in all six themes, four languages and three UI scales; the packaged application passed 35 smoke checks.
- The release workflow repeats the application suite, source and packaged smoke checks, real updater/rollback checks, and archive privacy/integrity verification before publishing the downloads.

## Deutsch

**Updates direkt in ED-Frame:** dezente Benachrichtigung, Prüfung unter Settings → About, optionaler Hintergrunddownload und Installation nach deiner Bestätigung. Automatische Downloads sind zunächst aus.

Der Updater prüft das Paket, wartet auf das Ende der App, sichert alle lokalen Profile und behält den bisherigen Programmordner. Baupläne, Wishlists, Zugangsdaten und gespeicherte Daten bleiben erhalten. Bei fehlgeschlagenem Austausch oder Start wird der vorherige Stand wiederhergestellt. Sicherungen und alte Programmordner bleiben für die Wiederherstellung erhalten und brauchen zusätzlichen Platz.

**1.0.11 einmal manuell installieren**, weil Versionen bis 1.0.10 keinen Updater enthalten: alte App inklusive Tray beenden, das gesamte Windows-ZIP in einen neuen Ordner entpacken und ED-Frame.exe starten. Dein vorhandenes AppData-Profil wird weiterverwendet. Danach stehen Updates in der App bereit. Der laufende Server 0.9.5 braucht dafür kein Update.
