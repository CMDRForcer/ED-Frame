# ED-Frame 1.0.12

Ready for the Anaconda Mk II and the October ship rebalance. ED-Frame now recognizes the new hull throughout the fleet, engineering and purchase browser, with its own ship graphic and all 38 physical slots.

## What's new

- **Anaconda Mk II:** complete hardpoints, eight utility mounts, military slots and the restricted Cargo01 slot. Mk II cargo racks, ablative armour, supported hangars and Mining Volley Repeater permissions are included. ARX early access is shown explicitly; an unannounced credit price or entitlement is never assumed.
- **Existing ships updated:** new internal slots on the Type-6, Type-7, Imperial Clipper and Federal Dropship, a third Asp Scout utility mount and the Clipper's larger fuel tank. Reviewed hull masses and finite flight references cover all ten ships affected by Frontier's October 20 update, including Mandalay and Caspian Explorer.
- **Your plans stay attached:** existing physical slot names and module/wishlist bindings are retained when a new slot is added. Shield/thruster fit checks use updated hull references. No profile migration is required.
- **Clear reference information:** hull mass, base shield and the approximate published Mandalay/Caspian jump ranges appear as references in the ship browser. Actual loadout mass, cargo capacity and jump range continue to come from your Journal.
- **Armour and browser fixes:** stock versus Mk II ablative armour remain distinct through storage, export and purchase. Selecting a ship scrolls its catalog card into view, including at increased UI scale.

Catalog server **0.9.5** remains compatible. Its reference data has been refreshed without replacing API/collector code or discarding observed ship prices. The private administrator tool is not included in this release.

## Install

From **1.0.11**, open **Settings → About** and use the updater, or extract the complete **ED-Frame-1.0.12-Windows.zip** into a new writable folder. Keep `_internal` beside `ED-Frame.exe`. Versions through **1.0.10** require manual installation. Existing data under `%LOCALAPPDATA%/ED-Frame` is reused; keep your normal backups.

## Data and validation

References are pinned to the reviewed October 20 EDSY snapshot and checked against [Frontier's patch notes](https://steamcommunity.com/app/359320/announcements/). Raw flight parameters in the notes are not substituted for stock-reference speeds. For the Type-7, the officially announced single class-7 addition is applied to the previous verified layout rather than importing a conflicting extra class-6 slot from that snapshot. Unknown acceleration/thermal values are omitted; no maximum cargo figure is invented.

Validation covers the complete application suite, real QML startup and page interactions, physical-slot uniqueness, preserved installed/planned bindings, fit references and the Anaconda module/armour rules. The Windows release workflow additionally verifies the packaged app, update/rollback behavior, checksums and archive privacy before publishing downloads. Anaconda Mk II Journal scenarios use synthetic fixtures; an owner's live Mk II Journal was not available for this release.
