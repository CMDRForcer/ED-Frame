# ED-Frame 1.0.5 — Powerplay evidence fixes

This maintenance update fixes gaps in Mining Finder's Powerplay evidence handling and accompanies catalog server 0.9.1.

- **Acquire:** explicit unoccupied target systems are preserved, including observations with no participating Powers. They can be assessed independently of the selected Power's presence.
- **Freshness:** control, state and contesting participants retain their own observation times. Facts older than 24 hours or without a usable time remain unconfirmed; a fresh market or presence update cannot refresh them.
- **Clear status:** outdated Powerplay evidence has a separate label. Exact server checks distinguish outdated observations from systems not yet observed.
- **Correct participants:** newer complete system snapshots replace old contesting membership. Timestamp comparison handles offsets and fractional seconds correctly.

Coverage still depends on actual public observations. Missing data stays unknown; confirmed routes do not guarantee in-game merit payouts or mining yield. Retained profile data and history are preserved.

**Download:** extract `ED-Frame-1.0.5-Windows.zip` into a separate folder and run `ED-Frame.exe` with `_internal` beside it. Your existing profile is reused. Source code and SHA-256 checksums are included as separate assets.

Historical tags 1.0.1–1.0.4 were already occupied, so 1.0.5 is the first maintenance release following the new ED-Frame 1.0. Existing tags and downloads remain unchanged.
