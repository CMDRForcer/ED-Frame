# Local module fitting reference

Generated by `tools/build_module_fit_reference.py`, never fetched at runtime.
The JSON includes pinned source commits, not an unversioned live dependency.

- Module masses, mass limits, draw and standard costs: [EDCD/coriolis-data](https://github.com/EDCD/coriolis-data). Reference costs are NOT station purchase observations.
- Hull-specific reservations, undersizing and installation limits: game-data facts from [taleden/EDSY](https://github.com/taleden/EDSY). EDSY attributes Elite Dangerous game data to Frontier Developments; its program code is CC BY-NC 4.0. No EDSY program code is included or executed. See the source's attribution and licence notice.

Only an exact symbol match provides module evidence. New/unknown modules or
hulls remain unverified. Refresh this export explicitly when game data changes.
Power draw is a standard-module reference. Where every participating module has
known reference draw and no installed engineering, a replacement draw/reactor
comparison is shown. Cargo hatch, priorities and engineering are not evaluated;
power remains a warning rather than a fit exclusion.

Shield mass uses hull mass. Thruster mass uses a matching Journal Loadout snapshot,
full fuel and cargo capacity, and the standard replacement-minus-old-module mass.
Missing or stale snapshots, unknown/engineered old thruster mass remain unverified.
Replacing the selected singleton slot is allowed; other occupied slots count
toward the limit. Weapon-stabiliser exceptions remain unverified.
